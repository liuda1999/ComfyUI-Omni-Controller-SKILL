# 经验与技术文档快速索引（Quick Index）

> **本文件是项目全部经验 / 问题排查 / 技术参考文档的统一检索入口。**
>
> 解决的问题：`EXPERIENCE.md` 等大文件内容庞杂、章节混写，难以快速定位到具体小节。
>
> 使用三步法：
>
> 1. 在「[2. 主题速查](#2-主题速查关键词--文件章节)」按**关键词 / 问题现象**找到 `文件:章节`（含行号）；
> 2. 对 `EXPERIENCE.md` 可再用「[3. 章节导航](#3-experiencemd-章节导航含行号)」确认小节范围；
> 3. 在编辑器中按行号跳转，或在文件内搜索该章节标题。
