# ComfyUI DPM++ 系列与 DDPM 采样器完全参考手册

**文档版本**：2.0
**适用对象**：ComfyUI 中级及以上用户
**覆盖范围**：dpmpp_2s_ancestral、dpmpp_2s_ancestral_cfg_pp、dpmpp_sde、dpmpp_sde_gpu、dpmpp_2m、dpmpp_2m_cfg_pp、dpmpp_2m_sde、dpmpp_2m_sde_gpu、dpmpp_2m_sde_heun、dpmpp_2m_sde_heun_gpu、dpmpp_3m_sde、dpmpp_3m_sde_gpu、ddpm


## 1. 预备知识：DPM++ 系列命名规则解读

在逐个了解之前，先掌握 DPM++ 采样器命名的“密码”，可以帮你举一反三：

| 后缀/标记 | 含义 | 对生成的影响 |
| :--- | :--- | :--- |
| **dpmpp** | DPM++ (Diffusion Probabilistic Model ++) 算法家族 | 比早期 DPM 精度更高、速度更快 |
| **2s / 2m / 3m** | 求解器阶数：**2s**=二阶单步，**2m**=二阶多步，**3m**=三阶多步 | 阶数越高，数学精度越高，细节越丰富，速度越慢 |
| **sde** | 随机微分方程 (Stochastic Differential Equation) | 引入随机性，画面更平滑自然，不收敛 |
| **ancestral** | 祖先采样器 | 每一步注入新噪声，结果多变、富有创意 |
| **_gpu** | GPU 优化版本 | 利用 GPU 并行计算加速，速度更快 |
| **_heun** | 使用 Heun 方法作为内部求解器 | 比默认的 midpoint 方法精度更高 |
| **_cfg_pp** | 带有 CFG++ 增强的提示词控制 | 提示词遵循度更高，边缘保留更好 |

> **重要概念**：**收敛型 vs. 随机型**
> - **收敛型**（如 `dpmpp_2m`）：去噪路径稳定，相同种子可复现，结构扎实。
> - **随机型**（如带 `sde` 或 `ancestral` 的）：路径带有随机游走，结果富有变化，画面更自然。


## 2. 各采样器详细介绍

### 2.1 `dpmpp_2s_ancestral` —— 二阶单步 + 祖先采样

- **核心机制**：DPM-Solver++(2S) 二阶单步求解器，配合祖先采样策略。每一步去噪后都会注入新的随机噪声，使路径带有“之”字形随机游走特性。
- **性能画像**：
  - **速度**：较快（DPM++ 家族中最简单的节点之一）
  - **质量**：纹理丰富，富有表现力
  - **确定性**：低（随机型，不收敛）
- **特点与最佳场景**：
  - **特点**：生成的图像纹理变化极大，适合需要“意外惊喜”的创作。由于是单步求解器，计算开销较低。
  - **弱点**：可能过度随机化细节，导致结构不够稳定。
  - **最佳场景**：概念艺术、风格化插画、需要丰富笔触感的场景。
  - **推荐步数**：20-30 步
  - **推荐调度器**：`karras`

---

### 2.2 `dpmpp_2s_ancestral_cfg_pp` —— 创意 + 提示词控制增强版

- **核心机制**：在 `dpmpp_2s_ancestral` 基础上集成了 CFG++ 增强机制。CFG++ 使得后续的校正阶段只需要调用无条件模型，从而在提升提示词遵循度的同时保持较高速度。
- **性能画像**：
  - **速度**：中等（略慢于非 cfg_pp 版本）
  - **质量**：在保持纹理丰富度的同时，提示词遵循度更高
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：这是“创意与控制的平衡者”。它既有祖先采样器的艺术自由度，又能更好地响应用户的提示词。
  - **最佳场景**：需要创意变化但又不希望完全脱离提示词控制的场景，如角色设计迭代、风格探索。
  - **推荐步数**：20-30 步
  - **推荐调度器**：`karras`

---

### 2.3 `dpmpp_sde` —— 随机微分方程基础版

- **核心机制**：基于随机微分方程 (SDE) 的 DPM++ 采样器。它在去噪过程中模拟了布朗运动的随机扩散过程，使图像过渡极其平滑。
- **性能画像**：
  - **速度**：慢
  - **质量**：极高，渐变和过渡非常自然
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：生成的图像具有“空气感”和“景深感”，尤其擅长处理光影渐变和景深虚化。
  - **弱点**：**显存占用较高**，对硬件有一定要求。
  - **最佳场景**：写实人像、产品摄影、需要柔和自然过渡的场景。
  - **推荐步数**：25-35 步
  - **推荐调度器**：`karras`

---

### 2.4 `dpmpp_sde_gpu` —— GPU 加速版 SDE

- **核心机制**：`dpmpp_sde` 的 GPU 优化版本。利用 CUDA 等并行计算技术，将大规模矩阵运算卸载到 GPU 上执行。
- **性能画像**：
  - **速度**：中等（比 `dpmpp_sde` 快）
  - **质量**：与 `dpmpp_sde` 相同
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：**核心算法与 `dpmpp_sde` 完全一致，仅计算设备不同**。如果你有性能足够的 GPU，应优先选择此版本。
  - **最佳场景**：所有需要使用 `dpmpp_sde` 但希望加速的场景，尤其是批量生成。
  - **推荐步数**：25-35 步
  - **推荐调度器**：`karras`

---

### 2.5 `dpmpp_2m` —— 行业黄金标准 ★

- **核心机制**：DPM-Solver++(2M) 二阶多步求解器。多步意味着它会利用前面几步的历史信息来优化当前步的计算，从而在较少的步数内达到高质量收敛。
- **性能画像**：
  - **速度**：快
  - **质量**：优秀，结构扎实，细节清晰
  - **确定性**：高（收敛型）
- **特点与最佳场景**：
  - **特点**：这是目前**公认的“行业黄金标准”** (industry gold standard)。它在速度、质量、稳定性之间取得了完美平衡。
  - **最佳场景**：**日常通用首选**。无论写实、二次元、还是商业设计，它都能稳定输出高水准图像。如果你不知道选什么，选它。
  - **推荐步数**：15-25 步即可达到极佳效果
  - **推荐调度器**：`karras`

---

### 2.6 `dpmpp_2m_cfg_pp` —— CFG 增强版黄金标准

- **核心机制**：在 `dpmpp_2m` 基础上集成 CFG++ 增强，提升了提示词控制力和边缘细节保留能力。
- **性能画像**：
  - **速度**：中等（略慢于 `dpmpp_2m`）
  - **质量**：在写实风格和提示词遵循度上表现极佳
  - **确定性**：高（收敛型）
- **特点与最佳场景**：
  - **特点**：被许多社区用户评价为“**最推荐的通用采样器**”。在处理复杂长提示词时，它能更好地保留每个 token 的权重影响。
  - **最佳场景**：提示词复杂、需要精确控制画面元素的场景；商业约稿中对质量要求较高的场合。
  - **推荐步数**：20-30 步
  - **推荐调度器**：`beta`（官方推荐）

---

### 2.7 `dpmpp_2m_sde` —— 平滑写实之王

- **核心机制**：将 `dpmpp_2m` 的高效多步求解与 SDE 的随机扩散相结合。它在保持 `2m` 速度优势的同时，引入了 SDE 的平滑特性。
- **性能画像**：
  - **速度**：中等（慢于 `2m`，快于 `3m`）
  - **质量**：极高，画面极为平滑自然
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：在处理**阴影和景深**方面表现极其出色。生成的图像具有“胶片感”，非常适合写实风格。
  - **最佳场景**：**写实人像特写**（皮肤质感、眼神光）、产品摄影（金属反光、玻璃折射）、需要柔和氛围的场景。
  - **推荐步数**：25-35 步
  - **推荐调度器**：`karras`

---

### 2.8 `dpmpp_2m_sde_gpu` —— GPU 加速版平滑写实

- **核心机制**：`dpmpp_2m_sde` 的 GPU 优化版本。算法与 `dpmpp_2m_sde` 完全一致，但利用 GPU 并行计算加速。
- **性能画像**：
  - **速度**：较快（比 `dpmpp_2m_sde` 快）
  - **质量**：与 `dpmpp_2m_sde` 相同
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：在批量生成高分辨率图像时优势明显。
  - **最佳场景**：所有需要使用 `dpmpp_2m_sde` 的场景，尤其是批量写真人像生成。
  - **推荐步数**：25-35 步
  - **推荐调度器**：`karras`

---

### 2.9 `dpmpp_2m_sde_heun` —— Heun 求解器版 SDE

- **核心机制**：`dpmpp_2m_sde` 的内部求解器默认为 `midpoint`（中点法），而此版本将求解器替换为 **Heun 方法**（二阶龙格-库塔法的一种）。
- **性能画像**：
  - **速度**：慢（Heun 需要两次函数评估，计算量更大）
  - **质量**：比默认 midpoint 版本更高
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：Heun 方法比 midpoint 具有更高的数值精度，能更准确地追踪扩散过程的微分方程轨迹。这使得生成的图像在细节保真度上略胜一筹。
  - **最佳场景**：**对质量有极致追求，且不介意牺牲速度**的场景。适合最终出图而非快速测试。
  - **推荐步数**：30-40 步
  - **推荐调度器**：`karras`

---

### 2.10 `dpmpp_2m_sde_heun_gpu` —— Heun 求解器 GPU 加速版

- **核心机制**：`dpmpp_2m_sde_heun` 的 GPU 优化版本。算法完全一致，计算在 GPU 上执行。
- **性能画像**：
  - **速度**：中等（比 `dpmpp_2m_sde_heun` 快）
  - **质量**：与 `dpmpp_2m_sde_heun` 相同
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：在拥有 GPU 的情况下，这是使用 Heun 求解器的最优选择。
  - **最佳场景**：追求 `dpmpp_2m_sde_heun` 质量但希望加速的场景。
  - **推荐步数**：30-40 步
  - **推荐调度器**：`karras`

---

### 2.11 `dpmpp_3m_sde` —— 三阶极致保真

- **核心机制**：DPM-Solver++(3M) 三阶多步求解器 + SDE。三阶意味着它利用前三步的历史信息进行更高精度的计算，数学上误差最小。
- **性能画像**：
  - **速度**：最慢
  - **质量**：理论最高保真度
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：它追求的是对扩散过程的“原教旨主义”还原。步数越多，边际收益越明显。
  - **最佳场景**：**超大幅面打印**、**科学研究级图像生成**、**复杂纹理**（毛皮、岩石、树皮等）的生成。
  - **推荐步数**：30-50 步
  - **推荐调度器**：`linear_quadratic`（官方推荐）或 `karras`

---

### 2.12 `dpmpp_3m_sde_gpu` —— GPU 加速版三阶保真

- **核心机制**：`dpmpp_3m_sde` 的 GPU 优化版本。
- **性能画像**：
  - **速度**：慢（比 `dpmpp_3m_sde` 快）
  - **质量**：与 `dpmpp_3m_sde` 相同
  - **确定性**：低（随机型）
- **特点与最佳场景**：
  - **特点**：在批量生成高质量图像时，GPU 版本能显著缩短等待时间。
  - **最佳场景**：追求 `dpmpp_3m_sde` 极致质量的批量生成任务。
  - **推荐步数**：30-50 步
  - **推荐调度器**：`karras`

---

### 2.13 `ddpm` —— 原始扩散模型（遗留）

- **核心机制**：去噪扩散概率模型 (Denoising Diffusion Probabilistic Model) 的原始采样方法。这是扩散模型的“祖师爷”，采用最原始的马尔可夫链去噪过程。
- **性能画像**：
  - **速度**：极慢
  - **质量**：稳定但精度一般
  - **确定性**：高（收敛型）
- **特点与最佳场景**：
  - **特点**：这是**最原始的扩散采样方法**，速度慢且精度不如现代采样器。在 ComfyUI 中主要用于**遗留系统兼容**或**学术研究对比**。
  - **最佳场景**：**不建议用于日常生成**。仅用于对比实验、研究扩散模型的原始行为，或兼容老旧工作流。
  - **推荐步数**：100-1000 步（原始论文设定）
  - **推荐调度器**：`ddim_uniform`


## 3. 快速选择指南

### 3.1 按场景选择

| 场景 | 推荐采样器 | 推荐调度器 | 推荐步数 |
| :--- | :--- | :--- | :--- |
| **日常通用（不知道选什么）** | `dpmpp_2m` | `karras` | 15-25 |
| **日常通用 + 提示词复杂** | `dpmpp_2m_cfg_pp` | `beta` | 20-30 |
| **写实人像 / 产品摄影** | `dpmpp_2m_sde_gpu` | `karras` | 25-35 |
| **写实人像 + 极致细节** | `dpmpp_2m_sde_heun_gpu` | `karras` | 30-40 |
| **艺术创作 / 风格探索** | `dpmpp_2s_ancestral` | `karras` | 20-30 |
| **艺术创作 + 提示词控制** | `dpmpp_2s_ancestral_cfg_pp` | `karras` | 20-30 |
| **极致保真 / 大幅面打印** | `dpmpp_3m_sde_gpu` | `karras` | 30-50 |
| **平滑渐变 / 柔和场景** | `dpmpp_sde_gpu` | `karras` | 25-35 |
| **学术研究 / 遗留兼容** | `ddpm` | `ddim_uniform` | 100+ |

### 3.2 按优先级选择

- **速度优先**：`dpmpp_2m` > `dpmpp_2s_ancestral` > `dpmpp_2m_sde_gpu`
- **质量优先**：`dpmpp_3m_sde_gpu` > `dpmpp_2m_sde_heun_gpu` > `dpmpp_2m_sde_gpu`
- **稳定性优先**：`dpmpp_2m` > `dpmpp_2m_cfg_pp` > `ddpm`
- **创意优先**：`dpmpp_2s_ancestral` > `dpmpp_2s_ancestral_cfg_pp` > `dpmpp_2m_sde_gpu`

### 3.3 GPU 版本选择原则

- 如果你的显卡性能足够（建议 RTX 20 系列及以上），**优先选择带 `_gpu` 后缀的版本**。
- `_gpu` 版本与不带 `_gpu` 的版本**算法完全一致，仅计算设备不同**。


## 4. 总结

DPM++ 系列是 ComfyUI 中**最强大、应用最广泛的采样器家族**。核心建议如下：

1.  **新手起点**：`dpmpp_2m` + `karras`，这是最安全、最高效的组合。
2.  **写实追求者**：`dpmpp_2m_sde_gpu` + `karras`，平滑自然的画面效果。
3.  **极致画质党**：`dpmpp_3m_sde_gpu` + `karras`，用时间换质量。
4.  **创意艺术家**：`dpmpp_2s_ancestral_cfg_pp` + `karras`，在创意与控制间取得平衡。
5.  **`ddpm` 不建议用于日常生成**，它更适合学术研究场景。
